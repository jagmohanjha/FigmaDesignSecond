# Wonderlust – Travel Website

Wonderlust is a travel website design created to make exploring destinations simple and visually appealing. It features a clean layout, destination cards, and a user-friendly interface inspired by a Figma design.

This project is currently being developed using HTML and CSS. I am focusing on recreating the design as closely as possible while learning how to build responsive layouts.

## Tech Stack

- HTML5
- CSS3
- Flexbox
- CSS Grid

## Features

- Clean and modern travel website UI
- Hero section with background image and call-to-action
- Featured destinations section with destination cards
- Navigation bar
- Footer with useful links
- Tablet layout
- Responsive design (Desktop and Mobile – In Progress)

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/jagmohanjha/FigmaDesign.git
   ```

2. Open the project folder:

   ```bash
   cd FigmaDesign
   ```

3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for a better development experience.

## Project Status

The tablet layout is currently being developed based on the Figma design. Desktop and mobile responsive layouts will be added next.
